# 👤 Face & Gender Detection

A real-time face detection and gender classification system built with OpenCV, deep learning, and Flask.

## 🚀 Features

- Real-time face detection using OpenCV
- Gender classification (Male / Female)
- Web interface powered by Flask
- Supports webcam and image upload input

## 🛠️ Tech Stack

- **Python**
- **OpenCV** – Face detection
- **Flask** – Web framework
- **Deep Learning Models** – Gender classification

## 📁 Project Structure

```
face-detection/
├── app.py               # Flask app entry point
├── detect.py            # Face & gender detection logic
├── models/              # Pre-trained model files
├── static/              # CSS, JS, assets
├── templates/           # HTML templates
└── requirements.txt     # Python dependencies
```

## ⚙️ Setup & Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/face-detection.git
   cd face-detection
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app**
   ```bash
   python app.py
   ```

4. Open your browser at `http://localhost:5000`
